## Question 2. Given the docker-compose.yaml, what is the hostname and port that pgadmin should use to connect to the postgres database?

  vol-pgdata:

    name: vol-pgadmin_data

## ## Question 3. Counting short trips

For the trips in November 2025 (lpep_pickup_datetime between '2025-11-01' and '2025-12-01', exclusive of the upper bound), how many trips had a `trip_distance` of less than or equal to 1 mile?


```sql
select COUNT(*) AS short_trip from `de_zoomcamp`.`ny_taxi`.`green_tripdata_2025_11`
where lpep_pickup_datetime < '2025-12-01'
and lpep_pickup_datetime >= '2025-11-01'
and trip_distance <= 1
```
- **8,007**


## Question 4. Longest trip for each day
Which was the pick up day with the longest trip distance? Only consider trips with trip_distance less than 100 miles (to exclude data errors).

Use the pick up time for your calculations.


```sql
select date(lpep_pickup_datetime), trip_distance from `de_zoomcamp`.`ny_taxi`.`green_tripdata_2025_11`
where trip_distance < 100
order by trip_distance desc
limit 1

--optimized
with daily_max AS (
  select 
    date(lpep_pickup_datetime) AS pickup_day,
    max(trip_distance) AS max_trip_distance
  from `de_zoomcamp`.`ny_taxi`.`green_tripdata_2025_11`
  where trip_distance < 100
  group by 1
)

select pickup_day, max_trip_distance
from daily_max
order by max_trip_distance desc
limit 1;

```

- **"2025-11-14"	88.03**

## Question 5. Biggest pickup zone
Which was the pickup zone with the largest total_amount (sum of all trips) on November 18th, 2025?


```sql
select 
  z.Zone, 
  sum(t.total_amount) as total_amount_sum
from `de_zoomcamp`.`ny_taxi`.`taxi_zone_lookup_1` as z
left join `de_zoomcamp`.`ny_taxi`.`green_tripdata_2025_11` as t
  on z.LocationID = t.PULocationID
where date(t.lpep_pickup_datetime) = '2025-11-18'
group by 1
order by 2 desc
limit 1

```
- **"East Harlem North"	9281.919999999996**

## Question 6. Largest tip
For the passengers picked up in the zone named "East Harlem North" in November 2025, which was the drop off zone that had the largest tip?

Note: it's tip , not trip. We need the name of the zone, not the ID.



```sql
select 
  dz.Zone as dropoff_zone,
  max(t.tip_amount) as max_tip
from `de_zoomcamp`.`ny_taxi`.`green_tripdata_2025_11` t
inner join `de_zoomcamp`.`ny_taxi`.`taxi_zone_lookup_1` pz
  on t.PULocationID = pz.LocationID
inner join `de_zoomcamp`.`ny_taxi`.`taxi_zone_lookup_1` dz
  on t.DOLocationID = dz.LocationID
where pz.Zone = 'East Harlem North'
  and t.lpep_pickup_datetime >= '2025-11-01'
  and t.lpep_pickup_datetime < '2025-12-01'
group by 1
order by 2 desc
limit 1

```

- **"Yorkville West"	81.89**
